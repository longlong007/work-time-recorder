# 工作时间记录器 — 演进路线图

> 以下是社区驱动的功能演进方向，不代表承诺实现。优先级会随社区反馈调整。

---

## v1.x — 当前稳定版

已在生产环境可用：
- 单次计时开始 / 结束
- 工作名称 + 标签分类
- 闹钟提醒（预设 + 自定义）
- 历史记录（筛选 / 编辑 / 删除）
- CSV 导入 / 导出
- 深浅主题切换
- PWA 离线支持
- Service Worker 更新策略（Stale-While-Revalidate）
- 键盘快捷键

---

## v2 — 协作与数据管理

目标：解决单机使用的局限性，支持多端同步与团队协作场景。

### 云端同步

- 用户账户体系（邮箱 / 微信登录）
- 数据实时同步到云端，localStorage 仅作离线缓存
- 冲突解决策略：以后写时间戳为准，保留本地草稿
- 迁移工具：把现有 localStorage 数据一键迁移到云端账户

### 多设备支持

- 手机 / 电脑 / 平板同一账户多端登录
- 正在进行的计时在各设备间同步展示
- 支持主动暂停 / 继续（跨设备）

### 数据导出增强

- 支持 JSON 格式完整导出（含元数据）
- 支持 Excel（.xlsx）格式导出
- 导出时可选择日期范围和标签过滤

### 定期任务

- 支持"每天固定时间提醒"的重复闹钟
- 支持周报 / 月报自动生成并推送通知
- 适合有固定作息的用户自动化记录

### 团队功能（基础）

- 团队空间，成员列表
- 匿名工作记录（不显示具体内容，只显示工作时长）
- 管理员可查看团队整体数据趋势

### 安全加固

- localStorage 数据可选端对端加密（用户自设密码）
- 敏感字段（工作内容）可选加密存储

---

## v3 — 智能化

目标：在记录之上叠加分析和洞察，让数据真正驱动决策。

### 数据分析仪表盘

- 日 / 周 / 月工作时长热力图
- 标签分布饼图（哪些类型工作花费最多时间）
- 效率趋势：对比历史同期工作时长变化
- 异常检测：某天工作时长过长或过短时提醒

### AI 工作建议

- 基于历史数据推荐最佳工作时间段
- 识别碎片化记录，提出整合建议
- 识别"忙到忘记结束"的情况，自动生成补录提醒

### 日历集成

- 同步到 Google Calendar / Apple Calendar
- 生成 ICS 日历文件一键导入
- 工作记录可发布为公开日历供他人订阅

### 番茄钟模式

- 内置番茄工作法（25min 工作 / 5min 休息循环）
- 番茄记录计入统计，与普通计时合并展示
- 番茄历史可导出分析

### 更多导入来源

- Google Calendar API 导入（识别会议等事件）
- Notion / Linear 等工具的 API 导入
- 浏览器扩展：自动记录标签页切换时间（需明确隐私政策）

---

## v4 及以后 — 平台化

> 早期规划，远景性质

- 开放 API，供第三方工具接入
- 插件系统，支持开发者贡献功能模块
- 工作流自动化（类似 Zapier / Make）：满足条件时自动触发记录、通知、导出
- 社区市场：分享和发现优秀的统计视图、导入适配器

---

## 非功能目标（持续改进）

- **性能**：大数据量（>10000 条）下的渲染和查询性能
- **无障碍**：支持屏幕阅读器，满足 WCAG 2.1 AA 标准
- **隐私合规**：符合 GDPR 要求的用户数据删除权、导出权、通知义务
- **国际化**：英文界面支持，日期 / 时间格式本地化
- **移动端体验**：独立设计移动端布局（当前响应式但非最佳）

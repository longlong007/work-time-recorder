## 快速上手

1. 打开 `index.html`（或访问在线地址）
2. 点击 **开始**，计时自动开始
3. 完成后点击 **结束**，记录存入历史
4. 在右侧历史区域查看所有记录

---

## 核心流程

### 开始

- 点击 **▶ 开始**，计时自动开始
- 可在"工作名称"输入框填写本次工作内容（选填，最多50字），或从「今日待办」下拉选择当天任务
- 可从快捷标签栏选择预设标签辅助分类

### 结束

- 点击 **⏸ 结束**，计时停止并存入历史
- 若设置了闹钟，时间到时会弹出提示并给出"继续计时"选项
- 结束后自动更新今日/本周/本月统计

---

## 待办清单

右侧 **✅ 待办** Tab 是按天清单，默认显示今天。

### 增删改查

- 顶部输入框填写任务，回车或点 **添加**
- 勾选完成，点标题可改文字，点 🗑️ 删除
- 用日期筛选查看历史某天；点 **今天** 回到当天

### 导入导出

- **📤 导出** 下载全部待办 CSV：`日期,标题,完成,排序`
- **📥 导入** 合并到现有待办（新 id）
- **清空** 只清空当前正在查看的那一天

### 和工时联动

开始前，可在工作名称左侧的 **今日待办** 下拉里选当天任务，选中后填入工作名称，仍可继续手改。不绑定待办 ID，改标题不影响已有工时记录。

## 标签管理

### 预设标签

默认提供五个预设标签：开发、会议、学习、调试、文档。点击标签可直接添加到当前工作名称。

### 自定义标签

1. 点击 **管理标签** 按钮打开标签弹窗
2. 在输入框输入标签名称（最多20字），点击 **➕ 添加**
3. 可通过拖拽调整标签顺序
4. 点击垃圾桶图标删除标签

## 闹钟功能

### 设置方式

- **预设时间**：点击 5分钟 / 10分钟 / 15分钟 / 30分钟 / 45分钟 按钮
- **自定义**：在输入框输入分钟数（1-480分钟），点击 **设置**

### 闹钟响起时

- 弹出提示弹窗，显示"时间到！"
- 可选 **继续计时**（不清除计时器）或 **结束**

### 开启系统通知

- 点击 **开启系统通知** 按钮获取浏览器通知权限
- 获取后，即使标签页在后台，闹钟也会触发系统通知

## 历史记录

### 查看记录

所有历史记录显示在右侧面板，按开始时间倒序排列。

### 筛选日期

- 选择日期后点击 **筛选**，只显示当天记录
- 点击 **重置** 恢复显示全部记录

### 编辑记录

- 点击记录行的 ✏️ 图标，打开编辑弹窗
- 可修改工作名称、开始时间、结束时间
- 点击 **💾 保存** 确认修改

### 删除记录

- 点击记录行的 🗑️ 图标，确认后删除
- 删除后不可恢复，请谨慎操作

## 导入导出

### 导出 CSV

- 点击 **📤 导出** 按钮，下载 `工作时间记录_YYYY-MM-DD.csv`
- CSV 格式：`日期,开始时间,结束时间,工作时长(小时),工作内容`

### 导入 CSV

- 点击 **📥 导入** 按钮，选择 CSV 文件
- 支持带引号包裹的字段（含逗号的工作内容）
- 单次导入最多 5000 条记录
- 文件大小限制 2MB
- 导入后按开始时间倒序合并到现有记录

**CSV 格式示例：**

```
日期,开始时间,结束时间,工作时长(小时),工作内容
2024-01-15,2024-01-15T09:00:00,2024-01-15T18:00:00,9.00,日常开发
2024-01-15,2024-01-15T14:00:00,2024-01-15T15:30:00,1.50,会议
```

## 界面与快捷键

### 主题切换

- 点击页面顶部的 ☀️/🌙 按钮切换深色/浅色模式
- 偏好设置会保存在本地，下次打开自动应用

### 键盘快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 开始 / 结束（在非输入框时生效） |
| `Ctrl + E` | 导出 CSV |
| `Ctrl + /` | 打开快捷键说明弹窗 |

### 快捷键说明弹窗

- 点击页面顶部的 ⌨️ 按钮可随时打开快捷键说明

## 渐进式安装

本应用支持 PWA（渐进式 Web 应用），可安装到桌面或手机桌面。

### 安装步骤

- **桌面端（Chrome/Edge）**：访问页面时浏览器地址栏右侧会出现安装图标，点击即可
- **移动端（Safari/Chrome）**：从浏览器菜单选择"添加到主屏幕"

安装后在桌面直接打开，与原生应用体验一致，支持离线使用。

## 数据说明

### 存储位置

所有数据保存在浏览器 `localStorage`，键名为：
- `work_records` — 历史工作记录
- `todos` — 按天待办
- `currentRecord` — 当前进行中的计时（如有）
- `work_tags` — 自定义标签列表
- `theme` — 界面主题偏好
- `more_settings_open` — 更多设置折叠状态

### 数据备份

- 定期通过 **导出** 功能备份 CSV 是最安全的做法
- localStorage 数据清除后无法恢复

### 跨天处理

- 若开始计时后跨天（如凌晨加班场景），再次打开页面时自动结束上一天的工作并保存记录

## 故障排除

| 问题 | 解决方法 |
|---|---|
| 计时器不走 | 刷新页面，检查是否关闭了标签页的省电模式 |
| 闹钟不响 | 点击"开启系统通知"授予通知权限，或检查浏览器通知设置 |
| 导入失败 | 确认 CSV 格式正确，文件大小不超过 2MB |
| 样式异常 | 尝试切换主题后刷新页面，或清除浏览器缓存 |
| 无法安装 PWA | 确认浏览器支持 PWA，或通过 GitHub Pages 在线使用 |
